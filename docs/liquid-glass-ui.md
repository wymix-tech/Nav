# 液态玻璃界面

基线：main `d407a4a`（已包含无限画布 V1、V2、V3）。开发分支：`feat/liquid-glass-ui`。

## 覆盖范围

网格和无限画布共用材质：内容导航、画布工具条、编辑工具、更多菜单、图层/搜索/视角面板、小地图、底部控制面板、组件库、组件操作按钮，以及偏好设置、组件配置、登录、安装、确认和关于弹窗。内置组件按钮也使用统一的状态反馈；隔离 iframe 中的第三方插件保留自身样式。

偏好设置采用分组表单、胶囊分段控件、内凹输入框和统一操作按钮；修正原来 90% 宽度配合窄容器导致的弹窗宽度问题。标签关联输入框，背景模式公开 aria-pressed 状态，关闭按钮有明确名称。

## 实现与维护

- `styles/main.css` 首先声明 `nav-base, nav-components` 层序，再加载组件；基础规则不会盖掉组件布局。
- 组件局部样式归入 `nav-components`。`styles/liquidGlass.css` 是统一材质层，集中管理颜色、玻璃高光、边缘、阴影、控件状态和弹窗分组。
- 玻璃使用渐变、半透明、backdrop-filter 和内高光，不增加运行时依赖、全屏 SVG 折射或指针追踪。只在容器做背景模糊，嵌入工具组及弹窗内表单不叠加模糊。
- 深浅主题沿用背景亮度判断；根元素主题也覆盖 Teleport 弹窗。禁用、焦点、选中、危险操作均有独立状态。
- 保留减少动画设置，增加减少透明度及不支持背景模糊时的实色回退。
- 相机持久化与 Runtime 生命周期保持不变。组件外观作为可选文档字段保存，继续使用 schema/document 3 和现有存储协议。该 Web 实现参考 Liquid Glass 视觉语言，并非 Apple 原生材质或逐像素复刻。

## 组件外观（第二阶段）

偏好设置新增“组件外观”：自动、通透玻璃、实色、无背景、原有外观。编辑模式中，将鼠标移到内置组件上，使用右上角“组件外观”按钮，可单独设置或恢复跟随全局。取消不写入；保存走现有文档事务、同步与撤销历史，不修改组件业务配置和几何位置。

新工作空间默认自动；既有文档没有 `widgetAppearance` 字段时沿用原有外观，迁移不会自动补写。全局使用 `Dashboard.widgetAppearance`，单组件使用 `WidgetInstance.appearance`；单组件字段缺省表示继承。均为经过枚举校验的可选字段，导出/导入、离线保存和冲突差异预览覆盖这些字段。旧客户端可能不会展示新外观，应更新前后端后使用。

自动模式下，时钟、天气、搜索、书签使用单层玻璃外壳；聊天、系统监控和 Docker 使用实色。天气移除内层重复模糊并适配主题文字，搜索采用胶囊输入框，书签保留简洁内容，聊天消息与代码区域保留稳定底色，监控状态色保持原来的高低负载含义并改善浅色主题对比度。实色、无背景、摘要显示不启用卡片背景模糊。

第三方插件继续保持原样；本阶段不更改 manifest 或 iframe 内部主题协议。

新增验证：`tests/appearance.test.ts` 覆盖旧数据、新默认、类型策略、枚举与序列化；存储回归覆盖全局及单组件外观差异；`tests/browser/widget-appearance.spec.ts` 覆盖七类组件在网格/画布、深浅主题和桌面/窄屏的渲染，以及保存、取消、撤销、重做、继承恢复和刷新持久化，并确认现有组件实例继续保留。
