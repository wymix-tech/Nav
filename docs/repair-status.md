## 明确的支持边界

- 此环境未执行 Docker 构建、真实 macOS Safari、Firefox/WebKit 实际运行及系统显示缩放测试。CI 已配置对应浏览器与 Docker 检查，仍需查看实际运行结果；不把配置存在当作检查通过。
- 插件安装/卸载需要网络，不进入仪表盘离线队列；已安装目录有本地缓存。避免离线声明安装成功却无法固定来源或处理引用顺序。
- SVG 不再公开返回；旧 SVG 需替换。旧插件不继续执行主页面代码，需要迁移到 v2，原配置与位置保留。
- 上传配额目前按文件数量限制。独立上传登记表、无人值守资源回收、自动字段级冲突合并未启用；不会自动删除历史上传文件。
- 资源阈值和 1600 px 默认宽度为首版策略。实际系统缩放、极端旧数据和大组件集合性能仍需部署环境验收。

升级必须先备份数据库和上传文件，并处理旧 root 卷的写权限。详细操作见 [upgrade-and-rollback.md](upgrade-and-rollback.md)。
