# V3 网格模式风格适配（2026-10-20）

网格模式沿用画布的半透明背景、细边框、圆角、线性图标和主题色状态，同时保留正常页面滚动、网格断点和布局持久化语义。

## 调整

- 自动整理、设为基准、断点重置使用共用控件风格；窄屏自动换行，不撑出窗口。
- 组件的拖拽、缩放和单列排序手柄统一图标、背景、边框及焦点样式；配置、删除入口使用共用 SVG 图标，保留 title 和可访问名称。
- 同步状态栏使用相同背景与按钮样式，网格中仍处于正常文档流。主控制面板的 Nav 品牌按钮去掉原生白色背景。
- 图层和搜索面板锚定顶部吸顶导航；统一面板标题、关闭图标、图层行、选择态和搜索结果样式。面板内部可滚动，不压缩网格列宽。
- 网格侧栏里的编辑工具使用嵌入式展开：次级命令进入侧栏滚动内容，不再向上弹出后被裁切。
- 清除选择使当前按钮禁用、焦点离开按钮时，已展开的编辑菜单仍能响应 Esc。关闭后恢复菜单或导航触发按钮焦点，未展开菜单不截断全局快捷键。

网格、画布共用的组件直接复用，未另建一套编辑命令或选择逻辑。未改变组件配置、布局算法、窗口变化不保存、一次拖拽一次提交、schema/document 3、Dexie 4、manifest 2 或 100 组件上限。

## 验证

浏览器使用隔离本地服务和 Chromium 153，通过 Playwright 实际渲染、截图、点击、滚动和键盘操作。截图检查了 1366 和 390 宽度的布局工具条与图层编辑面板，自动检查另外涵盖 1024 宽度，以及原有两种布局的 1920 / 1366 / 1024 / 390 窗口矩阵。

增强 `workspace-navigation.spec.ts`：网格编辑工具条与面板不超出窗口；两项选择后分组命令可用且进入视口；清除选择、两级 Esc 关闭、焦点恢复可用；这些导航与选择操作不改变 revision 和组件布局。原有拖拽、断点、跨标签同步、插件生命周期、聊天和画布测试继续保留。

本轮只声明 Chromium 验证；Firefox/WebKit 和真机检查仍待完成。此前 V3 性能与 WebKit 撤销问题不因风格适配关闭。

结果：115 项单元测试通过；V2、V3、dashboard 和内容导航的 Chromium 回归 32 passed。进一步补充布局工具条视口边界断言后，内容导航定向运行 1 passed。前后端类型检查、全仓 ESLint、前端生产构建、格式和差异检查通过。
