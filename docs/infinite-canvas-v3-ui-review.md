# V3 画布与工具条视觉复查（2026-10-19）

用户先反馈“图层 / 搜索画布”入口位置不合理，随后指出上下工具区挤占画布，且按钮与页面风格不一致。本次以铺满工作区的画布和悬浮控件替代此前占据正常文档流的上下工具区。

## 布局与视觉

- 画布覆盖整个可用工作区；导航、同步状态、组件库、右侧面板和底部工具条不参与画布宽高分配。
- 右上方为按内容宽度收缩的图层、搜索、我的视角工具条。窄屏使用图标，保留可访问名称和悬停说明。
- 底部居中为手形、缩放、适应全部、默认视角、小地图及列表切换；使用统一线性 SVG 图标、透明按钮、主题色状态和半透明玻璃背景。
- 资源模式、详情数量、发布默认视角收进“更多画布选项”。只有编辑时显示编辑工具；排列、分组、锁定、对齐等在次级弹层中。点击外部或 Esc 关闭弹层。
- 图层、搜索及视角面板覆盖右侧画布，展开不改变画布尺寸和相机。小地图在右侧面板打开时隐藏以免遮挡。
- 编辑时的同步栏也使用悬浮样式，组件库展开不再缩窄画布。窄屏将工具条放在组件库和主控制点上方，避免“更多”按钮被控制点挡住。
- 网格模式仍使用顶部吸顶工具条，不套用全屏悬浮画布布局。

## 实际浏览器检查

使用隔离本地服务和真实 Chromium，通过项目 Playwright 实际渲染、点击、输入和读取屏幕坐标，并检查浏览模式、搜索面板、编辑模式、组件库展开及窄屏截图。远程交互浏览器不能连接本地开发端口，未声称通过该远程浏览器打开页面。未连接生产数据。

首次复查的 12 组件网格中，1366 × 768 的“图层”按钮原本在 y=1177；1024 × 768 为 y=1717，390 × 844 为 y=3321，均在首屏之外。网格入口已置顶并在滚动时保持可见。

悬浮版本覆盖 1920 × 1080、1366 × 768、1024 × 768、390 × 844。浏览模式下断言画布矩形等于工作区，宽高等于窗口；打开右侧面板不改变画布矩形。编辑和组件库展开时，另外覆盖 1366、1024、390 三种宽度，画布仍为完整窗口矩形，工具条不超出窗口且可操作。

## 回归范围

`tests/browser/workspace-navigation.spec.ts` 覆盖两种布局、滚动后的入口、面板切换、搜索聚焦和 12 条结果、关闭、我的视角、无横向溢出、画布铺满、面板不挤压画布、编辑和组件库展开、选项 Esc 关闭与焦点恢复，以及导航不修改 revision 或组件布局。

已有 V2、V3、dashboard 测试随新菜单入口调整，保留原有功能断言。区域手势改从悬浮状态栏之外开始；拖放测试改用不与已有组件重叠的空白位置，避免混淆原有避碰插入逻辑与拖放坐标。

本轮仅声明 Chromium 验证。环境仍缺少 Playwright Firefox / WebKit 可执行程序，既有跨浏览器记录只代表此前版本。既有 `V3-WK-UNDO-01`、`V3-PERF-DENSE-01` 和真机验收事项不因视觉调整关闭。
